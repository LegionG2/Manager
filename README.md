Warsztat Manager Premium - poprawka UI / responsywność

Najważniejsze poprawki w tej wersji:
- lepsza praca na mniejszych ekranach
- poziome przewijanie tabel i formularza
- stabilniejsze przełączanie jasny / ciemny bez zmiany rozmiarów ramek
- domyślne wyszukiwanie po numerze zlecenia
- tryb wyszukiwania: Nr zlecenia / Wszystko
- filtrowanie po priorytecie
- filtr "Tylko pilne terminy"
- przycisk Backup do wykonania kopii bazy danych
- układ dzielony, który łatwiej dopasować do szerokości okna

Uruchamianie:
1. Python 3.x
2. uruchom main.py

Budowa EXE:
1. uruchom build_exe.bat
2. gotowy plik znajdziesz w folderze dist

Dane i ustawienia zapisują się lokalnie w:
C:\Users\NAZWA_UZYTKOWNIKA\AppData\Local\WarsztatManagerPremium\
